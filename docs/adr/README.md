# Registro delle Decisioni Architetturali (ADR) — Bardo AI
> Autore: Paolo Basta (https://github.com/Il-Basta-Paolo/BardoAI)

Questo archivio documenta le decisioni architetturali e ingegneristiche fondamentali adottate nello sviluppo di **Bardo AI**.  
Ogni record (ADR - *Architecture Decision Record*) descrive il contesto pratico al tavolo da gioco, il problema tecnico affrontato, la decisione presa, le conseguenze concrete sul software e le alternative scartate.

Il formato adottato segue lo standard [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
